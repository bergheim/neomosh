A fair comparison.

Each model received the same project brief and created its own three SVG marks independently. Claude and Grok were consulted through their own CLIs. Codex assembled the gallery and lightly edited captions for clarity; all mark geometry is model-authored. The wordmark, scale, and presentation are shared. The small samples show each mark at an actual 24 pixels, in one color.

These are first-round directions, not a selected identity. Use Color, Mono, and Night to compare silhouettes, then save any mark as an editable SVG. Downloads contain the symbol in its original accent color; the shared wordmark is only a presentation aid.
